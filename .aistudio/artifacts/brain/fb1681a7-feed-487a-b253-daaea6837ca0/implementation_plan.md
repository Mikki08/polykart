# Политех Спутник: 3-Вкладки Навигации, Multi-Design System и Figma Импорт

Полное перепроектирование мобильного приложения для студентов и преподавателей СПбПУ Петра Великого с поддержкой переключения между несколькими полнофункциональными стилями интерфейса (scrn.gallery inspired), умным поиском по естественному языку, оригинальной картой PolyMap и 3 главными разделами нижней панели.

---

## Key Features & Architecture

### 1. Переключатель Дизайнов Интерфейса (Multi-Design Theme System)
Вместо единого статичного вида, пользователь может на лету переключать **полноценные концепции UI** (не только цвета, но и расположение иконок, их размер, формат виджетов, стиль нижней панели, плотность и форму карточек):
- **Стиль 1: "Modern Minimal / Dynamic Dock"** (стилистика iOS/Dynamic Island) — лаконичный плавающий док с 3 иконками, карточки с радиусом 24dp, минималистичные контурные иконки, компактный формат виджетов.
- **Стиль 2: "Neumorphic Glass / Soft Polytech"** (стилистика frosted glass) — объёмные стеклянные панели, яркие градиентные плашки, крупный формат иконок в цветных кругах, плавающая шторка.
- **Стиль 3: "Compact Utility Grid"** (стилистика дашборда высокого разрешения) — высокая плотность информации, плоские карточки с четкой сеткой, крупные плашки с быстрым доступом, текстово-иконные бейджи.
- **Стиль 4: "Expressive Material You 3"** (стилистика Android 14+) — динамические чипы, асимметричные скругления, крупные акцентные кнопки, развернутые описания.

### 2. Умный Поиск по Естественному Языку (Smart Search)
- **Умный парсер**: обрабатывает сложные поисковые запросы на естественном языке.
  - *Пример*: `"преподователь химии у направления мехатроники и робототехники 1 курса группы 60002"`
  - *Результат*: выдает карточки преподавателей с их **фотографиями**, контактами и конкретной привязкой к типу занятий:
    - 👩‍🏫 **Полякова Вера Витальевна** — *Лекции по Химии* (Группа 60002, 1 курс, Мехатроника и робототехника)
    - 👩‍🏫 **Бочагина Татьяна Васильевна** — *Практические занятия по Химии* (Группа 60002, 1 курс)
    - 👨‍🏫 **Крылов Игорь Николаевич** — *Лабораторные работы по Химии* (Группа 60002, 1 курс)
- **Фильтрация и категории**: мгновенный поиск по группам, преподавателям, аудиториям, корпусам и сервисам.

### 3. Структура 3 Вкладок Нижней Навигации
Согласно требованиям, в нижней панели ровно **3 основных пункта**:
1. ⚡ **Сервисы** (`ServicesScreen`):
   - Центр управления: Полноэкранное недельное расписание RUZ SPbPU, список преподавателей с фото и профилями, ссылки на СДО Moodle, Личный Кабинет, Библиотеку, Новости Политеха и **Панель выбора дизайна UI**.
2. 🗺️ **Карта** (`PolyMapScreen`):
   - Оригинальная интерактивная векторная карта Политеха (PolyMap): интерактивный кампус, переключатель корпусов (Главный, Гидрокорпус, ИММЭиТ), селектор этажей (Цоколь, 1, 2, 3, 4 этажи), подсветка аудиторий и шторка расписания аудитории.
3. 🏠 **Главное** (`HomeScreen`):
   - Умная шапка с поисковой строкой и переключателем группы, виджет текущей/ближайшей пары с таймером обратного отсчета, временная шкала пар на сегодня (с прямой кнопкой перехода в СДО и на Карта PolyMap) и органайзер заметок/ToDo студента.

### 4. Руководство по Импорту Интерфейса в Figma

Пошаговая инструкция для переноса созданных макетов и стилей в **Figma**:

1. **Импорт макетов через скриншоты в Vector Frame**:
   - В эмуляторе приложения нажмите "Переключить дизайн", сделайте скриншоты каждого из 4 доступных UI-стилей.
   - В Figma используйте бесплатный плагин **«HTML to Design»** или **«Image to Figma»** для автоматического разбора растра в векторные автолейауты и текстовые слои.
2. **Экспорт векторной карты и иконок PolyMap**:
   - Файлы векторных иконок и схем PolyMap находятся в `app/src/main/res/drawable/` (`ic_polytech_logo.xml`, `ic_launcher_foreground.xml`, и др.).
   - Перетащите XML вектор в Figma с помощью плагина **«SVG Code Importer»** или конвертируйте в SVG.
3. **Привязка к Material 3 Design Kit**:
   - Откройте в Figma Community стандартный файл **Material 3 Design Kit**.
   - Установите переменную `Primary` = `#006B3F` (Polytech Green).
   - Все компоненты нашего Compose-кода (`Card`, `FilterChip`, `NavigationBar`, `TopAppBar`) соответствуют токенам этого кита.

## Пошаговый План Реализации

### Шаг 1: `UiDesignSystem.kt` — Движок стилей интерфейса
- Создать перечисление `UiStylePreset`: `MINIMAL_DOCK`, `NEUMORPHIC_GLASS`, `COMPACT_UTILITY`, `EXPRESSIVE_M3`.
- Реализовать `DesignThemeController` для переключения текущего стиля на лету.

### Шаг 2: `SmartSearchParser.kt` & Расширенная База Данных
- Добавить поле `photoUrl` / `photoRes` в карточку `Teacher`.
- Добавить `course`, `directionName`, `groupNumber` и детализацию типов занятий (Лекция, Практика, Лабораторная).
- Настроить парсер интеллектуального поиска для распознавания естественных запросов (например: `"преподователь химии у направления мехатроники и робототехники 1 курса группы 60002"`).

### Шаг 3: Переработка Навигации в `MainActivity.kt`
- Закрепить 3 пункта нижней панели: `Сервисы`, `Карта`, `Главное`.
- Все остальные подразделы (Недельное расписание, Умный поиск, Карточка преподавателя, Выбор стиля UI, Руководство Figma) открывать как дочерние экраны / шторки / вкладки внутри соответствующих разделов.

### Шаг 4: Обновление Экранов под Multi-Design Engine
- Поддержать адаптивную отрисовку в `HomeScreen`, `PolyMapScreen`, `ServicesScreen` и `TeachersScreen` в зависимости от выбранного пресета UI.

### Шаг 5: Проверка и Сборка
- Выполнить `compile_applet` и убедиться в полной работоспособности проекта без ошибок компиляции.
